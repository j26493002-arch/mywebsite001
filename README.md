نظام تسجيل الطلاب_BWP501 مشروع
## متطلبات التشغيل
 تثبيت XAMPP
 تشغيل Apache وMySQL من لوحة تحكم XAMPP
 استخدام متصفح ويب لتشغيل الموقع

## طريقة إعداد المشروع وتشغيله
1. نسخ مجلد المشروع إلى المسار C:\xampp\htdocs
2. فتح phpMyAdmin من خلال الرابط http://localhost/phpmyadmin
3. استيراد ملف student_registration_system.sql لإنشاء الجداول وإضافة البيانات
4. التأكد من تشغيل Apache وMySQL.
5. نسخ هذا الرابط إلى متصفح الويب لفتح الموقع:
   http://localhost/student_registration_system/

## طريقة استخدام الموقع
1. انشاء الحساب: يدخل المستخدم إلى صفحة التسجيل يختار إنشاء حساب يدخل اسم المستخدم والبريد الإلكتروني وكلمة مرور ويأكد كلمة مروره ثم يضغط إنشاء حساب
2. تسجيل الدخول: يمكن للمستخدم اختبار تسجيل الدخول إذا كان لديه حساب بالفعل باسم المستخدم أو البريد الإلكتروني مع كلمة مروره
3. إضافة طالب: يمكن للمستخدم إضافة طالب جديد من خلال إدخال الاسم والبريد الالكتروني ورقم الهاتف والعنوان ويمكنه ايضا اضافة صورة شخصية 
4. عرض الطلاب: يتم عرض الطلاب المسجلين بصفحة منفصلة ويمكن البحث عن اي طالب باستخدام اسمه او بريده الالكتروني أو رقم هاتفه ويمكن ترتيب الطلاب تصاعديا او تنازليا حسب الرقم او حسب الاسم
5. تعديل بيانات الطالب: يمكن تعديل اي خانة من الخانات ومنها الصورة الشخصية
6. حذف طالب: يمكن حذف اي طالب بعد تأكيد العملية
7. تسجيل الخروج: الضغط على زر تسجيل الخروج

## شرح الميزات البرمجية 
1. يمكن البحث عن الطلاب باستخدام الاسم أو البريد الالكتروني أو رقم 
يتم استخدام جملة SQL مع LIKE للبحث عن النتائج المطلوبة
2. يتم عرض 10 طلاب في كل صفحة لتسهيل تصفح البيانات نستخدم LIMIT و OFFSET في SQL لتحديد عدد السجلات المعروضة والانتقال بين الصفحات
3. يتم استخدام AJAX للتحقق من بعض الخانات في نموذج اضافة طالب مثل الاسم والبريد الالكتروني دون الحاجة لاعادة تحميل الصفحة يتم ارسال البيانات إلى ملف php للتحقق منها ثم عرض رسالة توضح وجود أي خطأ ان وجد
4. يستخدم النظام دالة password_hash()
لتشفير كلمة المرور قبل تخزينها في قاعدة البيانات وعند تسجيل الدخول يتم استخدام الدالة password_verify()
للتحقق من كلمة المرور المدخلة ومقارنتها بالكلمة المخزنة 
5. يتيح النظام اضافة صورة شخصية للطلاب يتم استخدام الدالة move_uploaded_file()
لنقل الصورة إلى مجلد uploads
يتم حفظ مسار الصورة في قاعدة البيانات
